관리자 패널

우주선 분위기에 맞춘 내부 관리창입니다. GitHub 설정과 메인·성향·NG·배려 리스트를 각각 관리할 수 있어요.

GitHub 저장소에 실제로 게시할 수 있습니다. 토큰은 이 페이지를 사용하는 동안에만 입력창에 보관하며, HTML·로컬 저장소·GitHub 파일에는 넣지 않습니다. 공개 저장소에 게시된 글은 방문자 화면에서도 자동으로 불러옵니다.

연결 메모

① 「GitHub 설정 저장」: 토큰을 제외한 설정만 이 브라우저에 저장합니다.

② 「GitHub에 게시」: 메인·성향·NG·배려 리스트를 JSON 파일로 실제 커밋합니다.

③ 「GitHub에서 불러오기」: 현재 저장소의 공개 데이터를 가져옵니다. 비공개 저장소는 토큰이 있어야 읽을 수 있고 일반 방문자에게는 보이지 않습니다.

토큰 권한: 선택한 저장소의 Contents → Read and write. GitHub에 게시된 데이터 파일에는 토큰이 포함되지 않습니다.

메인·성향·NG·배려 리스트를 각각 수정하세요. 04 배려 리스트는 자유 형식의 글 편집기에서 작성하고, 굵게·강조·색상·링크·이미지를 꾸밀 수 있어요. 방문자 화면에는 완성된 글만 표시됩니다.

글씨에 링크 삽입

링크를 넣을 글씨를 선택했으면 자동으로 채워져요. 직접 적어도 됩니다.

작동 방식

  1. 우주선 내부의 네모 모니터 4개를 클릭하면 작은 팝업이 열립니다.
  2. 방문자용 팝업은 읽기 전용이며 04 배려 리스트는 관리자에서 꾸민 글이 그대로 표시됩니다.
  3. 상단 톱니바퀴 버튼을 누르면 관리자 패널이 열립니다.
  4. 콘텐츠 편집에서 글을 수정한 뒤 GitHub 설정 → 「GitHub에 게시」를 누르면 사이트 방문자도 같은 내용을 볼 수 있습니다.

버튼 효과음

모니터·버튼·메뉴·링크를 누를 때 작은 게임풍 뿅뿅 효과음이 재생됩니다. 소리가 작게 설정되어 있으며 여기서 켜고 끌 수 있어요.
